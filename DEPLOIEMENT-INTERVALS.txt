MeRun-MeTrail : deploiement (depuis v4.6.0)

Le site Netlify thirdmarathon est relie a ce depot GitHub : chaque envoi sur la branche main redeploie
le site ET la fonction Intervals.icu (netlify/functions/intervals.mjs). Ne plus utiliser le glisser-deposer :
il ne publie pas la fonction.

Variables Netlify (Site configuration > Environment variables) :
  INTERVALS_API_KEY     cle API Intervals.icu (Settings > Developer Settings)
  INTERVALS_ATHLETE_ID  identifiant athlete, ex. i123456
  MERUN_CODE            code d'acces a saisir une fois dans l'appli (Plus > Montre)
Apres un changement de variable : Deploys > Trigger deploy (les fonctions lisent les valeurs du dernier deploiement).

Reglages Intervals.icu : relier Garmin Connect, cocher "Upload planned workouts" et "Download activities",
regler la FC max a 196.
