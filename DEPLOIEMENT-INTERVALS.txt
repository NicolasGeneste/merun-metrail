MeRun-MeTrail v4.6.0 : envoi des seances sur la montre via Intervals.icu

IMPORTANT : le glisser-deposer Netlify ne publie PAS les Netlify Functions.
A partir de cette version, deployer avec Netlify CLI (une seule fois a installer).

1. Installer Node.js LTS (https://nodejs.org), puis dans PowerShell :
     npm install -g netlify-cli
     netlify login
2. Dans le dossier dezippe (celui qui contient index.html et netlify.toml) :
     cd C:\chemin\vers\MeRun-MeTrail_v4.6.0
     netlify link            (choisir le site existant thirdmarathon)
3. Variables d'environnement (tapees dans ton terminal, jamais dans une conversation) :
     netlify env:set INTERVALS_API_KEY  "ta_cle_api"
     netlify env:set INTERVALS_ATHLETE_ID "i123456"
     netlify env:set MERUN_CODE "un_code_a_toi"
   (ou Netlify > Site configuration > Environment variables)
4. Deployer :
     netlify deploy --prod
   netlify.toml indique le dossier publie (.) et celui des fonctions (netlify/functions).
5. Sur le telephone : Plus > Montre · Intervals.icu > saisir MERUN_CODE > Enregistrer et tester.

Mises a jour suivantes : remplacer les fichiers puis relancer "netlify deploy --prod".

et "Download activities", regler la FC max a 196.
